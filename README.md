# Overview
This userscript adds Audio Panning (Left/Right) and Multi View features to Twitch (twitch.tv).
![screenshot](screenshot.jpg)
![screenshot](screenshot2.jpg)
![screenshot](screenshot3.jpg)
# Features
1. Pan
   - Assign each channel's audio to the left or right speaker independently.
2. Multi View
   - `Drag and drop` a channel card onto the upload icon, or `enter a channel name` and click the View button to the multi-view layout.
# Installation
1. **Install Tampermonkey**  
   - Chrome : [Tampermonkey](https://chromewebstore.google.com/detail/tampermonkey-%E3%83%99%E3%83%BC%E3%82%BF%E7%89%88/gcalenpjmijncebpfijmoaglllgpjagf)
   - Firefox : [Tampermonkey](https://addons.mozilla.org/ja/firefox/addon/tampermonkey/)

2. **Allow userscript**  
   Enable “Allow User Scripts” in the Extensions settings. For more details, see the official [FAQ](https://www.tampermonkey.net/faq.php?locale=en&q=Q209).

3. **Install Twitch-pan-and-multiview**    
   You can install it [here](https://github.com/grmpnk/Twitch-pan-and-multiview/raw/refs/heads/main/userscript.user.js)
